# LINYU Portfolio

一个原创的个人设计师 / 创意开发者作品集网站。页面采用纯 HTML、CSS 和 JavaScript 编写，无构建步骤、无框架依赖，适合直接修改和部署到 GitHub Pages、Cloudflare Pages 或 Netlify。

## 页面结构

- 极光风格首屏与悬浮导航
- 精选项目案例
- 个人介绍与经历数据
- 服务能力卡片
- 横向文字跑马灯
- 随笔文章区
- 联系转化区
- 桌面端和移动端响应式布局

## 本地使用

直接打开 `index.html` 即可预览。也可以使用任意静态文件服务器运行此目录。

## 修改内容

- 页面文字与项目内容：`index.html`
- 色彩、排版和响应式样式：`styles.css`
- 滚动入场与光标效果：`script.js`

建议优先搜索并替换以下示例信息：

- `林屿` / `LIN YU`
- `hello@example.com`
- 上海与个人经历数字
- 三个示例项目及文章标题
- 页脚社交平台链接

## GitHub Pages

推送至 GitHub 后，进入仓库的 **Settings → Pages**，选择从 `main` 分支根目录部署即可。

本项目参考了创意工作室网站常见的内容节奏与交互方式，所有页面代码、图形和示例内容均为重新设计，不包含参考品牌的商标或网站素材。
